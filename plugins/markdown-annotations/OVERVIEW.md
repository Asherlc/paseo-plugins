# Markdown annotations

Review Markdown files in Paseo and add comments about specific passages to an agent conversation.

Open a file with **Markdown annotations**, then select text or enter a line range in **Source**. Write a comment and choose a conversation in the workspace. **Add to chat** appends the path, line numbers, quote, and comment to that conversation's draft. Open the chat to review and send the message.

Requires Paseo 0.16.2 or later. The plugin supports `.md`, `.markdown`, `.mdown`, and `.mkd` files. The file panel is read-only. An annotation becomes part of the agent prompt when you send the draft.
